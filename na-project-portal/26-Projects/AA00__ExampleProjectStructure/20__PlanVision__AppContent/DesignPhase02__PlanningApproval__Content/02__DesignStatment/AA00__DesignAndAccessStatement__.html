1.0 - Introduction

This example statement demonstrates the Markdown to HTML Design & Access Statement route. It is authored in Typora, synced into the project portal, converted to HTML by the ProjectVision DAS builder, and mirrored to the Cloudflare R2 CDN for crisp, selectable display inside PlanVision.

The key benefit of this route is that text remains sharp at any zoom level and can be copied, unlike the rasterised PDF fallback.
