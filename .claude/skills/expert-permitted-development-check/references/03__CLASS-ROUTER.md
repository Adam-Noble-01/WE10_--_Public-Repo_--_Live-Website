# Class Router — which Class does this element fall under?

Getting the Class wrong invalidates the whole appraisal. Route each element,
then run that Class's checklist. **One scheme routinely engages three or four
Classes.**

## Elements expressly kicked out of Class A

A.1(k) removes these from Class A even though they are "enlargement,
improvement or other alteration". They need their own Class, or planning
permission:

| Element | Excluded by | Goes where |
|---|---|---|
| Verandah, balcony, **raised platform** (>0.3 m) | A.1(k)(i) | **Nowhere** — planning permission |
| Microwave antenna | A.1(k)(ii) | Class H |
| Chimney, flue, soil and vent pipe | A.1(k)(iii) | Class G |
| **Any alteration to any part of the roof** | A.1(k)(iv) | Class B or C |

The last one catches people constantly: **a rear extension whose roof ties into
the main roof slope is doing two things at once.** The extension is Class A; the
alteration to the existing roof is Class B or C, and must satisfy that Class
independently. The guidance makes this point at pp. 8–9.

## Where one scheme spans several Classes

Work each element against its own Class, then state the scheme verdict as the
**weakest** element. A scheme is permitted development only if **every** element
is permitted development.

> Example — "single-storey rear extension with two rooflights in the existing
> roof, a new flue, and a garden room at the bottom of the plot":
> - extension → **Class A**
> - rooflights in the *existing* roof → **Class C** (0.15 m protrusion limit)
> - flue → **Class G** (1 m above the ridge)
> - garden room → **Class E** (2.5 m if within 2 m of a boundary; 50% curtilage
>   test shared with the extension)
>
> Four checklists. And the extension and the garden room **share** the 50%
> curtilage ground-cover budget — A.1(b) and E.1(b) both measure *all* buildings
> in the curtilage other than the original house.

## Route by where the site is

| Site condition | Effect |
|---|---|
| **Flat / maisonette** | No Part 1 rights at all — stop |
| **Listed building** | Class E barred in the curtilage (E.1(g)); Part 2 Class A barred; solar barred (Part 14 A.1(2)(g)); LBC needed for everything |
| **Conservation area / AONB / National Park / the Broads / WHS** (= article 2(3) land) | A.2 restrictions; **Class B unavailable entirely** (B.1(f)); E.3; G.1(c); H.1(e); **Class AA unavailable** (AA.1(b)(i)) |
| **AONB / the Broads / National Park / WHS** (narrower than article 2(3) land) | E.2 — 10 m² cap on buildings more than 20 m from the house |
| **SSSI** | Larger rear extension unavailable (A.1(g)); **Class AA unavailable** (AA.1(b)(ii)) |
| **Article 4 direction** | Named rights withdrawn — check with the LPA |
| **Condition on a planning permission** | May remove PD rights entirely — art 3(4) |
| **House built under Part 20** | No Part 1 rights — A.1(l), B.1(g), C.1(e), D.1(e), E.1(k), F.1(b), G.1(d), H.1(f) |
| **House created under Part 3 Class G, M, MA, N, P, PA or Q** (+ O for Class AA) | No Part 1 rights |
