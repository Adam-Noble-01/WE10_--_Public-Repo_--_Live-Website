User Guide

The default navigation mode. Rotate, pan, and zoom around the model freely.

PC — Mouse
  • Left Button + Drag Rotate view around model
  • Right Button + Drag Pan camera
  • Middle Button + Drag Pan camera
  • Scroll Wheel Zoom in / out
Touchscreen
  • 1 Finger Drag Rotate view around model
  • 2 Finger Drag Pan camera
  • 2 Finger Pinch Zoom in / out

First-person navigation inside the building. Activate using the navigation toolbar or press the Walk mode hotkey (see View Mode Shortcuts below).

PC — Keyboard
  • W  /  ↑ Walk forward
  • S  /  ↓ Walk backward
  • A  /  ← Strafe left
  • D  /  → Strafe right
  • Shift Sprint (hold while moving)
PC — Mouse
  • Left Click Canvas Lock pointer to activate mouse look
  • Move Mouse Look around (no button held)
  • Esc Release pointer lock / stop mouse look
Touchscreen
  • 1 Finger Drag Move — forward, backward, and strafe
  • 2 Finger Drag Look around (head rotation)
  • 2 Finger Pinch Move forward / backward

Free-flight navigation through and around the building with no gravity or collision. Activate using the navigation toolbar or press the Fly mode hotkey (see View Mode Shortcuts below).

PC — Keyboard
  • W  /  ↑ Fly forward
  • S  /  ↓ Fly backward
  • A  /  ← Strafe left
  • D  /  → Strafe right
  • E  /  Space Ascend
  • Q  /  C Descend
  • Shift Boost speed (hold while moving)
  • Alt Slow / precision movement
PC — Mouse
  • Left Click Canvas Lock pointer to activate mouse look
  • Move Mouse Aim direction (yaw and pitch)
  • Esc Release pointer lock / stop mouse look
Touchscreen
  • 1 Finger Drag Horizontal movement (forward, backward, strafe)
  • 2 Finger Drag Camera rotation (yaw and pitch)
  • 2 Finger Pinch Vertical movement (spread = ascend, pinch = descend)
  • Switch to Orbit mode

  • Switch to Fly mode

  • Reset View

Use these Tools menu options to simplify what you see. They are useful for client presentations when you want to focus on one part of the building at a time.

  • Storey Toggle Turn individual floors on or off in any combination. Best for custom cutaway views and comparing several levels together.
  • Floor Isolate Shows one floor at a time. Roofs and landscape are switched off so the selected level is easier to understand in detail.
  • Show Entire Building Resets visibility to the full building view when you are done isolating.

Full screen hides the browser toolbars and address bar so the model fills the whole display. It is the best way to view a design, and you can switch it off again at any time.

  • Full Screen Found in the Tools & Settings menu. Select it to go full screen, and select it again to come back out. The badge next to it reads ON while full screen is active.
  • Escape Leaves full screen instantly at any time. In Walk or Fly mode the first press releases the mouse cursor, so press it a second time to return to the normal browser window.
  • Touchscreen Tablets and phones have no Escape key, so use the Full Screen option in the Tools & Settings menu to switch it off. The menu stays available while full screen is active.
