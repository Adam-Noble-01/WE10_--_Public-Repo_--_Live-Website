User Guide

Orbit Mode

The default navigation mode. Rotate, pan, and zoom around the model freely.

PC — Mouse
  • Left Button + Drag Rotate view around model
  • Right Button + Drag Pan camera
  • Middle Button + Drag Pan camera
  • Scroll Wheel Zoom in / out
Touchscreen
  • 1 Finger Drag Rotate view around model
  • 2 Finger Drag Pan camera
  • 2 Finger Pinch Zoom in / out

Walk Mode

First-person navigation inside the building. Activate using the Tools menu or the hotkey below.

PC — Keyboard
  • W  /  ↑ Walk forward
  • S  /  ↓ Walk backward
  • A  /  ← Strafe left
  • D  /  → Strafe right
  • Shift Sprint (hold while moving)
PC — Mouse
  • Left Click Canvas Lock pointer to activate mouse look
  • Move Mouse Look around (no button held)
  • Esc Release pointer lock / stop mouse look
Touchscreen
  • 1 Finger Drag Move — forward, backward, and strafe
  • 2 Finger Drag Look around (head rotation)
  • 2 Finger Pinch Move forward / backward

Global Hotkeys

  • Alt + Shift + W Toggle Walk Mode / Orbit Mode
