**YOUR OBJECTIVE** |  Your are tasked with developing the codebase for the ThermalCalcTool.

**PROJECT DESCRIPTION**
- The ThermalCalcTool is a web application that allows users to calculate the U-Value of building components.
- All calculation are to be fully compliant to ISO 6946:2017(E) standards.
- The application calculates U-Values based on material properties selected by users through dropdown menus populated from a JSON data file.

- Material thickness handling:
  - Standard products (marked with "is-product": true in JSON):
    - Fixed thicknesses only
    - No manual override allowed
    - Examples: insulation boards, cavity wall products, items or products sold only in standard thicknesses.
  
  - Variable thickness materials:
    - User-editable thickness fields
    - Examples: timber stud walls, joist floors
    - Useful for existing buildings with non-standard dimensions
    - Materials like timber have constant thermal conductivity but variable thicknesses
    - Existing solid brick walls where different brick sizes are used, or where the brick sizes are not standard.

- The application automatically determines whether thickness inputs should be editable based on the "is-product" property in the JSON data.

     - lambda    :  Validated Thermal conductivity of the material
     - r_value   :  Validated Thermal resistance of the material
     - notes     :  General notes about the material
     - info      :  Information about the material from the manufacturer / supplier / technical data sheets
     - warnings  :  Warnings / key considerations / omissions / limitations regarding the material
     - source    :  Source of the material
